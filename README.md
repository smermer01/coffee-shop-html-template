# Café Cocon

Maltepe, Yalı Mahallesi'nde evden çalışanlar için sıcak bir kahveci: üç tek kişilik ses yalıtımlı çalışma odası, altı küçük masa, iyi kahve ve Fransız fırını lezzetleri.

- `index.html` — Café Cocon ana sayfası
- `images/` — sayfadaki fotoğraflar
- `cafe-alto/` — sitenin temel aldığı orijinal Café Alto şablonu (uiuxlabz/coffee-shop-html-template; kişisel ve ticari kullanım serbest)

Yayına almadan önce: `index.html` içindeki `WHATSAPP_NUMARASI` değerini ve köşeli parantezli yer tutucuları ([FİYAT], [ADRES] vb.) doldurun.
